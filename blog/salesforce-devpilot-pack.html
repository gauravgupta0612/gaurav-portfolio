Salesforce DevPilot Pack: know what your change will break

Bringing my Salesforce years back into VS Code with dependency graphs, risk scores and one-click release checks.

By Gaurav Gupta · 18 October 2026 · 5 min read · Latest v1.0.0

Before IBM i and Java, I spent years building on Salesforce, and the question that always came up before a release was "what else does this change touch?". Salesforce DevPilot Pack, released on 18 October 2026, answers it inside VS Code, and all the analysis runs locally.

What's in the pack

  • Change Impact Analyzer. Builds a dependency graph of the SFDX project (Apex, triggers, LWC, Aura, Flows, Visualforce, objects, fields, permission sets) and follows every dependent of your changes, with the dependency path, for example Region__c → AccountService → accountList.
  • Risk score from 0 to 100, weighted by component type, depth, deletions and findings such as SOQL/DML in loops, tests without assertions, SeeAllData=true and changed Apex with no test.
  • Recommended tests that cover the changed code, runnable in one click.
  • One-click Health Check and Release Check, an Apex Log Analyzer and Test Intelligence.
  • GitLab and Jenkins reports through a small CLI with no npm dependencies.

It also installs the standard Salesforce Extension Pack, Prettier, the XML extension and ESLint, so one install sets up a full workstation.
