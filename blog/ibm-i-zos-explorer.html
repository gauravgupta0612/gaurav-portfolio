IBM i & z/OS Explorer: two platforms, one sidebar

A single extension for developers who work on both IBM midrange and mainframe systems.

By Gaurav Gupta · 9 October 2026 · 4 min read · Latest v1.1.0

Many enterprise developers move between IBM i and z/OS during the same week, and usually need two sets of tools to do it. IBM i & z/OS Explorer, released on 9 October 2026, puts both behind one icon in the VS Code sidebar.

z/OS, over z/OSMF REST

  • Data sets, PDS/PDSE members and USS files: browse, edit and save back, with an ETag check if someone else changed the member.
  • Submit JCL, follow jobs and read spool output; run TSO and MVS console commands.
  • Search inside a PDS, copy and rename members, view data set attributes, and generate compile/link/run JCL from templates (1.1.0).

IBM i, over SSH and SQL

  • Libraries, source members and IFS; library list and current library; compile with errors in Problems.
  • Run CL and SQL (sortable grid with CSV export), view spooled files, active jobs and job logs, and reply to QSYSOPR messages.
  • Object actions such as DSPOBJD, DSPPGMREF and DSPFFD, plus an SSH (PASE) terminal.
