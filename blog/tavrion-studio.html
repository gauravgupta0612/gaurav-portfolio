Tavrion Studio: an IDE that speaks Eclipse

Why I built a lightweight, VS Code-style IDE for Eclipse workspaces, and what ships in the Windows installer.

By Gaurav Gupta · 12 November 2026 · 7 min read · Latest v1.5.0

Eclipse is still where much of the enterprise Java world lives, with plug-in projects, .target platforms and carefully tuned launch configurations. VS Code feels lighter and faster, but it has never quite understood an Eclipse workspace. Tavrion Studio is my attempt to have both: the editor experience of VS Code with an engine that reads Eclipse projects the way Eclipse does.

The project began on 12 November 2026 under the working name Nexora Studio. Four builds (1.0 to 1.3) went out under that name the same day. To avoid any naming conflicts, it was renamed Tavrion Studio for version 1.4, and the source moved to its own public repository.

What it does

  • Eclipse compatibility. Reads .project, .classpath and JDT compliance settings, builds dependent projects first in Eclipse order, and imports and exports Eclipse .launch files.
  • Run and debug. Launch configurations live in .tavrion/launch.json. The debugger is built on JDWP and jdb and supports conditional breakpoints, hit counts, logpoints, Run to Line, watch expressions, a call stack and hover-to-inspect values.
  • Java editing on Monaco. Eclipse templates (sysout, main, foreach…), auto-import, Organize Imports, Outline, Go to Definition and Open Type, with javac errors shown inline.
  • PDE and OSGi. Set a .target file as the target platform. Bundles come from local p2 and Maven caches first, then from the p2 repositories, and Equinox or Felix launches start with the Gogo shell.
  • Developer Toolbox. Environment Doctor, a TODO/FIXME finder, Ports and Processes, and a REST client, all one shortcut away.
  • Beyond Java. It also opens TypeScript, React, React Native/Expo, Python, Go, Rust, C/C++ and .NET projects.

Download

Tavrion Studio ships as two Windows executables on every release: Setup (Start menu and desktop shortcuts, with a choice of install folder) and Portable (no installation needed). It needs a JDK, version 8 or later; 11, 17 or 21 is recommended.

Note on Windows SmartScreen

The executables are not code-signed yet, so Windows may show a warning. Choose More info → Run anyway.

Skills applied

Electron, Node.js, Java (javac, JDWP/jdb debugger), Eclipse JDT & PDE model, OSGi (Equinox/Felix), p2 & Maven resolution, Monaco editor, Windows installer (NSIS)
