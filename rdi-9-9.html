IBM Rational Developer for i 9.9

Every 9.9 version and fix pack in one place, with release dates, what each one fixed, and where to download it. Current level: 9.9.0.8 (FP8).

What changed in 9.9

  • New platform: Eclipse 4.31 base and IBM Java 21 (21.0.10.1 from FP2), with eGit 7.3.
  • Languages: RPG and COBOL language updates; new CL and DDS templates in FP5.
  • Security: multi-factor authentication from FP4, and security updates in FP1, FP6, FP7 and FP8.
  • Install: IBM Access Client Solutions (ACS) is no longer bundled with 9.9. Install and update through IBM Installation Manager; see IBM's update guide.

For plug-in developers, the move to Eclipse 4.31 and Java 21 usually means updating the target platform, bundle version ranges and Import-Package entries, and running regression tests on 9.9 before shipping.
